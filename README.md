# UKHousingMarket
HM Land Registry Price Paid Data - analysed incl. AI/agentic layer.

Analyses of HM Land Registry Price Paid Data (Greater London, last 5 jaar, limited to 100000 due to resource issues). DuckDB, AI layer, and dashboard.
## Setup
1. `pip install -r requirements.txt`
2. Plaats `pp-data.csv` in `data/` (HM Land Registry Price Paid Data, London-filter)
3. Run `notebooks/01_explore.ipynb` om de database op te bouwen
